Test Workloads

Experimental Setup & Datasets

🏥

Healthcare Aggregation

Simulated aggregation of electronic health records — patient demographics, diagnosis codes, and treatment outcomes. Sensitive features processed without exposing individual records.

💳

Financial Risk Analysis

Synthetic transaction data for credit risk modeling and fraud detection. Intensive numeric computation including multi-party matrix operations over GF(p).

🤖

Federated ML Training

Federated training of logistic regression model across 5 organizations. Accuracy compared against centralized baseline — variance below 1.8% across 5 repeated trials.

⚙️ Hardware Configuration

Each node: 8-core CPU, 32 GB RAM, 1 Gbps network bandwidth. Virtual machines distributed across geographically separated data centers.

🐳 Container Stack

Docker + Kubernetes for orchestration. EasySMPC framework with adaptive orchestration extensions. TLS 1.3 between all nodes.

📏 Node Range

Tested with 4, 6, 8, 10, 12, 16 active nodes. KPI monitoring at 5-second intervals. Auto-scaling triggers at 1.5s latency or 80% network utilization.

🔁 Repeatability

5 experimental runs per configuration. Standard deviation <3% across runs, confirming framework reproducibility and statistical consistency.
