THE CORE CONCEPT

What is SMPC?

Secure Multi-Party Computation (SMPC) lets multiple parties jointly compute a function over their inputs while keeping each party's data completely private.

Three hospitals want to find the average patient recovery rate across their combined data — but none wants to share records. SMPC makes this possible, computing the result without any party ever seeing another's raw data.

Our project builds a cloud-ready, containerized framework integrating SMPC with Kubernetes orchestration, Shamir's Secret Sharing, and ML inference — tested across healthcare, finance, and federated learning workloads.

How It Works

01
🔀

Input Sharing

Data owners split sensitive datasets into cryptographic shares using Shamir's Secret Sharing. Distributed to cloud nodes — raw data never leaves the client.

Shamir SSS · AES-256-GCM
›
02
⚙️

Secure Computation

Cloud nodes execute SMPC protocols on shares — exchanging only encrypted intermediate values. No node sees another party's data.

BGW Protocol · TLS · EasySMPC
›
03
🔗

Output Reconstruction

Partial results combined via Lagrange interpolation to reconstruct the final output. Only authorized parties receive it.

Lagrange · Threshold-k
